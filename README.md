### Goggles & Lens

My two-layer prompting method. Both layers stay on until I change them.

- **Goggles** set the *field*: the expertise, methods, and standards the AI works to.
- **Lens** sets the *perspective*: how it reasons and what it puts first.

```
GOGGLES: security QA engineer
LENS:    adversarial, assume it's broken
```

### How I work

1. Write testable requirements first.
2. Steer the build with Goggles & Lens. AI agents take a small, scoped share.
3. Check every result against the instructions, not against how confident the AI sounds.
4. Use the live app like a user would, and find what's broken.
5. Nothing ships unless every test passes. Unfinished items get listed openly.
