MERCYZERO

A deterministic security-testing and evidence platform.

Most security scanners give you a list of warnings and a shrug. MERCYZERO runs a seeded, repeatable test against a target. One component, and only one, decides pass or fail. Then it proves the result: it replays the run byte for byte, shrinks the failure to the smallest request that still breaks, fingerprints it, and seals everything into a content-hashed digest.

It ships with a Fastify API, a button-only web console, a public demo mode that can't touch a live system, and a separate chaos harness on Neon database branches.

  • 1,004 tests: 999 pass, 0 fail, 5 run in the database gate
  • Architecture is enforced in CI. Forbidden imports between modules fail the build.
  • Deploys only on green. Railway ships main only after the full gate passes.
  • Open issues are public. Residual risks live in ISSUES.md, not in a drawer.

SLAav

An SLA authority layer for Zendesk-style support teams.

When a support SLA is breached, someone pays, and the platform's own logs can be edited. SLAav records every SLA event in an append-only ledger that rejects changes, links each entry into an HMAC-SHA256 hash chain, sorts breaches into five root causes, and gives finance and operations a dollar figure they can defend.

  • 193 tests run against a live Postgres in CI
  • Hash chain checked independently. A test recomputes every HMAC and requires an exact match.
  • 14 adversarial ingestion tests. Bad data goes to quarantine and is never quietly fixed up.
  • Every claim pinned to a commit and a CI run in its evidence package.

02 / Method

How I build with AI

Prompting asks for an answer. Directing sets up a system where the wrong answer can't ship. This is the loop behind every project above.

01

Spec the system

I write the architecture, the module boundaries, and the forbidden dependencies before any code exists.

02

Gates before features

CI checks for architecture, contracts, lockfiles, and tests. Agents work inside rails they can't skip.

03

Direct the agents

I assign scoped work to AI agents and review every diff against the spec, not against good intentions.

04

Attack my own work

Adversarial tests and independent verification. If the system says it's correct, a second path checks.

05

Ship evidence

Claims point to commits and CI runs. Known gaps are written down. Nothing gets waved through.

"Claims track commits and CI runs, not intent."
